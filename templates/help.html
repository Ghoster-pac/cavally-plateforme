Mode d'emploi

Plateforme de suivi des travaux CET — Projet CAVALLY.

1. Indiquer votre nom

En haut à droite, saisissez votre nom. Il est mémorisé dans votre navigateur et attaché à chaque modification (traçabilité). Aucun compte n'est nécessaire : l'accès se fait par le lien partagé.

2. Saisir l'avancement

Deux façons de travailler :

  • Par tâche (recommandé) : choisissez un lot, puis une tâche (ex. « POSE RÉSEAU EF »). La liste des locaux s'affiche ; renseignez l'avancement, le statut et une observation. Le remplissage groupé applique une valeur à toutes les lignes affichées (filtrées par niveau).
  • Par local : depuis un lot, cliquez sur un local pour renseigner toutes ses tâches et un commentaire général.

Chaque champ est enregistré automatiquement (quelques centaines de millisecondes après la dernière frappe).

3. Statuts

  • Non démarré · En cours · Terminé · Bloqué · Non conforme · À vérifier

Le statut global d'un local et sa moyenne sont recalculés automatiquement à partir des tâches.

4. Importer

Page Importer : déposez un classeur rempli (même modèle) pour fusionner les données. Utile pour réintégrer un fichier travaillé hors ligne.

5. Générer le fichier Excel

Page Exporter : téléchargez le classeur complet, identique au modèle, rempli avec les saisies de tous les intervenants.

6. Installer l'application sur votre téléphone / ordinateur

La plateforme est une application web installable (PWA) : pas besoin de magasin d'applications.

  • Android (Chrome) : menu ⋮ → « Installer l'application » / « Ajouter à l'écran d'accueil ».
  • iPhone / iPad (Safari) : bouton Partager → « Sur l'écran d'accueil ».
  • Windows / macOS / Linux (Chrome / Edge) : icône « Installer » dans la barre d'adresse.

Une icône « CAVALLY » apparaît alors comme une vraie application.

7. Travailler sans réseau (hors-ligne)

Sur le terrain, sans connexion, vous pouvez continuer à saisir :

  • Le voyant en haut à droite affiche ● hors ligne et le nombre de saisies en attente.
  • Vos modifications sont conservées sur l'appareil et envoyées automatiquement dès que le réseau revient (le voyant passe à « synchronisé »).
  • Les dernières données connues restent consultables hors connexion.

Conseil : ouvrez la page d'un lot au moins une fois avec du réseau pour que ses données soient disponibles hors-ligne.

Raccourcis utiles

  • Filtrer par niveau puis « Remplissage groupé » pour traiter un étage entier rapidement.
  • Le libellé « voir toutes les tâches → » ouvre la fiche complète d'un local.
